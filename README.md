# Retail Sales Performance Analysis

## Project Overview
This project analyzes retail sales performance using Python, SQL, Excel, and Power BI. The goal is to clean and prepare sales data, identify business trends, detect outliers, and create a dashboard for monitoring key sales and profit metrics.

## Tools Used
- Python
- Pandas
- SQL
- Excel
- Power BI
- Jupyter Notebook

## Project Workflow
1. Cleaned and prepared Superstore sales data
2. Created SQL-ready dataset
3. Analyzed monthly profit trends
4. Detected sales outliers
5. Wrote SQL queries for business performance analysis
6. Built a Power BI dashboard for visual reporting

## Key Analysis
- Monthly profit trend analysis
- Sales performance tracking
- Outlier detection
- SQL-based business KPI analysis
- Power BI dashboard visualization

## Files Included
- Power BI dashboard
- Jupyter notebook
- SQL query file
- Cleaned datasets
- Monthly profit trend output
- Sales outlier output


## Business Impact
This project helps businesses understand sales performance, monitor profit trends, identify unusual sales behavior, and make better data-driven decisions using interactive reporting.
